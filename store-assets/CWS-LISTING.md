# Chrome Web Store listing draft

## Title

Zovo PageVault

## Summary

Save complete web pages locally, search every snapshot, compare versions, and annotate preserved copies.

## Detailed description

Keep a private, searchable record of pages that matter—even after the live site changes.

PageVault saves a page as self-contained HTML using the proven SingleFile capture engine. Images, styles, fonts, and frames are embedded into the preserved copy, then stored locally in your browser. Open the library to search words inside every saved page, not just titles and URLs.

Create automatic archive rules for the sites you follow. A rule can save after each completed visit and keep the latest number of versions you choose. Earlier and later snapshots can be rendered side by side, or overlaid to make visual changes easier to spot. Annotations belong to one exact snapshot: select text inside the saved copy, add a note, and the quote is highlighted on that version.

Core capture, local version history, full-text search, and one automatic site rule are free. A valid paid licence unlocks unlimited rules, visual comparison, and annotations; current plans are at https://zovo.one/pricing. Licence activation sends only the entered key and product identifier to the verification service.

Your archive stays in the browser. There is no advertising, analytics, sale of browsing data, or remote executable code. Export any snapshot as ordinary HTML whenever you want a portable copy.

PageVault is open source under AGPL-3.0-or-later and built on SingleFile: https://github.com/theluckystrike/zovo-pagevault
